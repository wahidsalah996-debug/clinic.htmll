# Dental Clinic Management System — Project Generator

This repository contains a Python setup script that generates a starter project for exploring clinic workflows with a React/TypeScript frontend, FastAPI backend, and PostgreSQL.

## Quick start
1. Install Python 3.10+.
2. Review `setup_clinic.py` before running it.
3. Run `python3 setup_clinic.py` to generate the project folder.
4. Enter the generated folder, review the configuration, and follow its generated README.

**Important:** the generated application is a starter prototype. GitHub Pages cannot host its backend or database.

## Before running
- Replace all placeholder credentials and generate a unique, strong application secret.
- Do not commit a real `.env` file, API keys, patient information, or production credentials.
- Review the code and dependency versions; run tests and a security review before deployment.
- Do not use real patient data until privacy, access control, backups, logging, and applicable data-protection obligations have been reviewed.

## Scope
This repository currently provides a project-generation script; it should not be represented as a production-ready medical system.
